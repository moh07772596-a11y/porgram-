أمثلة عملية لتشغيل الأكواد من الهاتف

مثال Python في Pydroid 3

أنشئ ملفًا جديدًا باسم main.py في محرر التطبيق، الصق المثال واضغط زر التشغيل. المحاكاة هنا للشرح فقط ولا تشغّل الكود على الهاتف.

numbers = [12, 8, 5]
print("المجموع:", sum(numbers))

مثال JavaScript عبر Termux

بعد تثبيت Node.js في Termux، احفظ النص في main.js ثم شغّله بالأمر node main.js. تحقق من توافق الحزم قبل تثبيتها.

const scores = [12, 8, 5];
console.log("المجموع:", scores.reduce((sum, score) => sum + score, 0));
