مكتبة الأكواد والحلول البرمجية (Developer & Apps Script Library)

مثال تعليمي يقرأ نطاقًا محدودًا من الورقة، ويرسل محتواه إلى OpenAI API، ثم يكتب الملخص في العمود F. لا تشغّله على بيانات حساسة.

Google Apps Script · JavaScript 
// Store OPENAI_API_KEY in Apps Script Project Settings > Script Properties.
// Never paste the API key into the sheet or share it with untrusted editors.
function summarizeSheetRange() {
  const apiKey = PropertiesService.getScriptProperties()
    .getProperty('OPENAI_API_KEY');
  if (!apiKey) {
    throw new Error('Add OPENAI_API_KEY to Script Properties first.');
  }

  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const rows = sheet.getRange('A1:D20').getDisplayValues()
    .filter(row => row.some(cell => cell.trim() !== ''));
  if (rows.length === 0) {
    throw new Error('The selected range is empty.');
  }

  const response = UrlFetchApp.fetch(
    'https://api.openai.com/v1/chat/completions',
    {
      method: 'post',
      contentType: 'application/json',
      headers: { Authorization: 'Bearer ' + apiKey },
      payload: JSON.stringify({
        model: 'gpt-4o-mini',
        messages: [{
          role: 'user',
          content: 'Summarize these spreadsheet rows in Arabic. Do not invent data:\n'
            + JSON.stringify(rows)
        }],
        temperature: 0.2
      }),
      muteHttpExceptions: true
    }
  );

  const status = response.getResponseCode();
  if (status < 200 || status >= 300) {
    throw new Error('OpenAI API request failed: ' + status);
  }

  const result = JSON.parse(response.getContentText());
  const summary = result.choices[0].message.content;
  sheet.getRange('F1').setValue('AI summary');
  sheet.getRange('F2').setValue(summary);
}

قبل التشغيل: أضف المفتاح في خصائص المشروع، وامنح Apps Script الأذونات المطلوبة. عند تشغيل المثال تُرسل خلايا A1:D20 إلى OpenAI؛ راجع سياسة مزوّد الخدمة وتكاليف API ولا تستخدم بيانات شخصية أو سرية.

مثال JavaScript: تنظيف قائمة قيم قبل استخدامها

تأخذ الدالة نصًا متعدد الأسطر، وتزيل الفراغات وتستبعد الأسطر الفارغة، ثم تعيد قائمة نظيفة. المتغير rawText هو النص المدخل وcleanRows هي النتيجة.

JavaScript · تشغيل في Console المتصفح أو مشروعك 
function cleanRows(rawText) {
  return rawText
    .split('\n')
    .map((row) => row.trim().replace(/\s+/g, ' '))
    .filter(Boolean);
}

const rawText = '  Alice  \n\n  Bob   Smith  ';
console.log(cleanRows(rawText));
  1. split('\n') يقسم النص إلى أسطر.
  2. map يزيل الفراغات حول كل سطر ويختصر الفراغات الداخلية.
  3. filter(Boolean) يحذف الأسطر الفارغة، ثم تعرض console.log النتيجة.

مثال Python: حساب مجموع عمود رقمي

تستقبل الدالة قائمة قيم، وتتجاهل القيم التي لا يمكن تحويلها إلى رقم. المتغير values هو المدخل وtotal هو المجموع.

Python · Python 3 
def sum_numeric_values(values):
    total = 0.0
    for value in values:
        try:
            total += float(value)
        except (TypeError, ValueError):
            continue
    return total

sales = [120, "85.5", "غير متاح"]
print(sum_numeric_values(sales))
  1. تبدأ الدالة مجموعًا بقيمة صفر.
  2. تحاول تحويل كل عنصر إلى رقم عشري؛ وتتخطى النصوص غير الرقمية بأمان.
  3. تعيد المجموع، وتعرضه print. غيّر قائمة sales إلى بيانات تجريبية خاصة بك.
